## The word

**donely** — *the false 'done' an agent reports while the real work is still queued behind a retry.*

## Why this word

Every agent user has felt it: the cheerful "done!" that arrives while the actual work is still sitting in a queue behind a retry that hasn't happened yet. It isn't a lie and it isn't a mistake — it's a premature finish, and English had no word for it. **Donely** names that exact moment: a finish claimed before the work is finished.

Built from "done" the way English grows words — the way "only" and "lonely" sit on the tongue — it is short, sayable, and spellable on first hearing. Say it once and you can use it forever: *"Don't give me donely, show me the finished work."*
